# Frontend Design Skill

Create distinctive, production-grade frontend interfaces with high design quality. Use this skill when the user asks to build web components, pages, or applications. Generates creative, polished code that avoids generic AI aesthetics.

## Key Principles

**Design Strategy**: Understand context first—purpose, target audience, tone, and technical constraints—before committing to an aesthetic direction. Rather than defaulting to safe choices, pick an intentional style, whether "brutally minimal" or "maximalist chaos."

**Aesthetic Execution**: Avoid clichéd patterns like:
- Overused font families (Inter, Roboto, Arial, system fonts)
- Clichéd color schemes (particularly purple gradients on white backgrounds)

Instead:
- Use distinctive typography that pairs display and body fonts creatively
- Build cohesive, high-contrast color palettes using CSS variables
- Add purposeful motion and animations (CSS-preferred for HTML)
- Create unexpected spatial layouts with asymmetry and generous negative space
- Include atmospheric details—textures, gradients, custom elements

## Implementation Philosophy

Match code complexity to the aesthetic vision:
- Maximalist designs warrant elaborate animations
- Minimalist designs demand restraint and precision
- Elegance comes from executing the vision well, not merely applying intense effects

The goal is creative interpretation and context-specific character—no two designs should converge on identical solutions.

## What This Skill Does

This skill provides guidance and frameworks for:

1. **Understanding the design brief** - asking clarifying questions about purpose, audience, and constraints
2. **Developing aesthetic direction** - choosing a distinctive visual approach
3. **Implementing with code** - writing HTML/CSS/React that executes the vision
4. **Attention to detail** - typography, color, spacing, motion, and atmospheric elements
5. **Avoiding generic patterns** - steering clear of overused designs and clichéd approaches

## When to Use This Skill

Use this skill when:
- Building new UI components or pages
- Redesigning interfaces for better aesthetics and usability
- Creating landing pages, dashboards, or marketing sites
- Styling React components with Tailwind CSS
- Implementing custom HTML/CSS layouts
- Adding visual polish and distinctive branding to applications
