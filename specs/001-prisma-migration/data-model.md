# Data Model: Prisma ORM Schema

**Feature**: Replace Supabase Client with Prisma ORM
**Date**: 2025-12-20
**Based on**: [spec.md](./spec.md) | [research.md](./research.md)

## Overview

This document defines the Prisma schema for dopeshot's database, including three managed tables (brand_profiles, user_metadata, generated_assets) and their relationship to the externally-managed auth.users table (managed by better-auth).

## Schema Relationships

```
auth.users (external - managed by better-auth)
  ├─> brand_profiles (1:1) - brand identity data
  ├─> user_metadata (1:1) - subscription & onboarding
  └─> generated_assets (1:many) - user's created screenshots
```

## Entity Definitions

### User (External)

**Source**: auth.users table (managed by better-auth)
**Ownership**: Managed by better-auth, referenced by Prisma
**Schema**: auth

| Field | Type | Required | Default | Description |
|-------|------|----------|---------|-------------|
| id | UUID | Yes | uuid() | Primary key, generated by better-auth |
| email | String | No | - | User email address |
| createdAt | DateTime | Yes | now() | Account creation timestamp |
| updatedAt | DateTime | Yes | now() | Last update timestamp |

**Relations**:
- `brandProfile`: One-to-one with BrandProfile
- `userMetadata`: One-to-one with UserMetadata
- `generatedAssets`: One-to-many with GeneratedAsset

**Notes**:
- Marked as external table in prisma.config.ts
- Prisma will not generate migrations for this table
- Foreign keys from managed tables reference this table

---

### BrandProfile

**Purpose**: Stores user's brand identity (colors, typography, logo)
**Schema**: public
**Table Name**: brand_profiles

| Field | Type | Required | Default | Description |
|-------|------|----------|---------|-------------|
| id | String (cuid) | Yes | cuid() | Primary key |
| userId | String (UUID) | Yes | - | Foreign key to auth.users.id (unique) |
| name | String | No | null | Optional brand name |
| colorPalette | Json | No | null | JSON: `{ primary, secondary, accent, background, text }` |
| typography | Json | No | null | JSON: `{ headingFont, bodyFont, fontWeights }` |
| logoPath | String | No | null | Path to logo in Supabase Storage (brand-logos bucket) |
| createdAt | DateTime | Yes | now() | Profile creation timestamp |
| updatedAt | DateTime | Yes | now() | Auto-updated on modification |

**Relations**:
- `user`: Many-to-one with User (auth.users)

**Validation** (runtime via Zod):
```typescript
colorPalette: {
  primary: string,
  secondary: string,
  accent: string,
  background: string,
  text: string
}

typography: {
  headingFont: string,
  bodyFont: string,
  fontWeights?: {
    heading?: number,
    body?: number
  }
}
```

**Indexes**:
- Unique index on `userId` (enforces 1:1 relationship)

**Constraints**:
- ON DELETE CASCADE (deleting user deletes brand profile)
- userId must be unique (one brand profile per user)

---

### UserMetadata

**Purpose**: Stores subscription, onboarding progress, and usage tracking
**Schema**: public
**Table Name**: user_metadata

| Field | Type | Required | Default | Description |
|-------|------|----------|---------|-------------|
| id | String (cuid) | Yes | cuid() | Primary key |
| userId | String (UUID) | Yes | - | Foreign key to auth.users.id (unique) |
| subscriptionTier | String | Yes | "free" | Subscription tier: "free" or "paid" |
| subscriptionStatus | String | Yes | "active" | Status: "active", "cancelled", "past_due" |
| onboardingProgress | Json | No | null | JSON: `{ completedSteps: string[], currentStep?: string }` |
| featureFlags | Json | No | null | JSON: `Record<string, boolean>` |
| exportsThisMonth | Int | Yes | 0 | Count of exports this month (for free tier limits) |
| createdAt | DateTime | Yes | now() | Metadata creation timestamp |
| updatedAt | DateTime | Yes | now() | Auto-updated on modification |

**Relations**:
- `user`: Many-to-one with User (auth.users)

**Validation** (runtime via Zod):
```typescript
onboardingProgress: {
  completedSteps: string[],
  currentStep?: string
}

featureFlags: Record<string, boolean>

subscriptionTier: "free" | "paid"
subscriptionStatus: "active" | "cancelled" | "past_due"
```

**Indexes**:
- Unique index on `userId` (enforces 1:1 relationship)

**Constraints**:
- ON DELETE CASCADE (deleting user deletes metadata)
- userId must be unique (one metadata record per user)
- subscriptionTier enum constraint (database level)
- subscriptionStatus enum constraint (database level)

---

### GeneratedAsset

**Purpose**: Stores references to user-generated screenshot exports
**Schema**: public
**Table Name**: generated_assets

| Field | Type | Required | Default | Description |
|-------|------|----------|---------|-------------|
| id | String (cuid) | Yes | cuid() | Primary key |
| userId | String (UUID) | Yes | - | Foreign key to auth.users.id |
| storagePath | String | Yes | - | Path to image in Supabase Storage (generated-assets bucket) |
| settingsSnapshot | Json | Yes | - | JSON: settings used to generate this asset |
| orientation | String | No | null | "landscape", "portrait", or "square" |
| textOverlays | Json | No | null | JSON: array of text overlay configurations |
| metadata | Json | No | null | JSON: `{ fileSize, dimensions: { width, height }, format }` |
| isPublic | Boolean | Yes | false | Whether asset is publicly shareable |
| createdAt | DateTime | Yes | now() | Asset creation timestamp |

**Relations**:
- `user`: Many-to-one with User (auth.users)

**Validation** (runtime via Zod):
```typescript
settingsSnapshot: {
  layout: string,
  orientation: "landscape" | "portrait" | "square",
  styleToggles: Record<string, boolean>,
  textOverlay?: string
}

metadata: {
  fileSize: number,
  dimensions: {
    width: number,
    height: number
  },
  format: string
}

orientation: "landscape" | "portrait" | "square"
```

**Indexes**:
- Composite index on `(userId, createdAt DESC)` for efficient recent assets queries

**Constraints**:
- ON DELETE CASCADE (deleting user deletes all assets)

## Prisma Schema File

```prisma
// prisma/schema.prisma

generator client {
  provider = "prisma-client-js"
}

generator json {
  provider = "prisma-json-types-generator"
  useType = "Any"
}

datasource db {
  provider  = "postgresql"
  url       = env("DATABASE_URL")
  directUrl = env("DIRECT_URL")
  schemas   = ["public", "auth"]
}

// External table (managed by better-auth)
model User {
  id        String   @id @default(uuid())
  email     String?  @unique
  createdAt DateTime @default(now()) @map("created_at")
  updatedAt DateTime @default(now()) @updatedAt @map("updated_at")

  // Relations to managed tables
  brandProfile    BrandProfile?
  userMetadata    UserMetadata?
  generatedAssets GeneratedAsset[]

  @@map("users")
  @@schema("auth")
}

// Managed tables (public schema)

model BrandProfile {
  id           String   @id @default(cuid())
  userId       String   @unique @map("user_id")
  name         String?

  /// [BrandColorPalette]
  colorPalette Json?    @map("color_palette")

  /// [BrandTypography]
  typography   Json?

  logoPath     String?  @map("logo_path")
  createdAt    DateTime @default(now()) @map("created_at")
  updatedAt    DateTime @updatedAt @map("updated_at")

  user User @relation(fields: [userId], references: [id], onDelete: Cascade)

  @@map("brand_profiles")
  @@schema("public")
}

model GeneratedAsset {
  id           String   @id @default(cuid())
  userId       String   @map("user_id")
  storagePath  String   @map("storage_path")

  /// [AssetSettings]
  settingsSnapshot Json     @map("settings_snapshot")

  orientation  String?

  /// [TextOverlays]
  textOverlays Json?    @map("text_overlays")

  /// [AssetMetadata]
  metadata     Json?

  isPublic     Boolean  @default(false) @map("is_public")
  createdAt    DateTime @default(now()) @map("created_at")

  user User @relation(fields: [userId], references: [id], onDelete: Cascade)

  @@index([userId, createdAt(sort: Desc)])
  @@map("generated_assets")
  @@schema("public")
}

model UserMetadata {
  id                 String   @id @default(cuid())
  userId             String   @unique @map("user_id")
  subscriptionTier   String   @default("free") @map("subscription_tier")
  subscriptionStatus String   @default("active") @map("subscription_status")

  /// [OnboardingProgress]
  onboardingProgress Json?    @map("onboarding_progress")

  /// [FeatureFlags]
  featureFlags       Json?    @map("feature_flags")

  exportsThisMonth   Int      @default(0) @map("exports_this_month")
  createdAt          DateTime @default(now()) @map("created_at")
  updatedAt          DateTime @updatedAt @map("updated_at")

  user User @relation(fields: [userId], references: [id], onDelete: Cascade)

  @@map("user_metadata")
  @@schema("public")
}
```

## Database Configuration

### External Tables Configuration

```typescript
// prisma.config.ts
import { defineConfig } from "prisma/config";

export default defineConfig({
  experimental: {
    externalTables: true,
  },
  tables: {
    external: [
      "auth.users",
      "auth.sessions",
      "auth.accounts",
      "auth.verifications",
    ],
  },
});
```

### Environment Variables

```bash
# Connection pooling (pgBouncer) - for Prisma Client
DATABASE_URL="postgresql://user:password@host:6543/db?pgbouncer=true&schema=public,auth"

# Direct connection - for Prisma CLI (migrations, introspection)
DIRECT_URL="postgresql://user:password@host:5432/db?schema=public,auth"
```

## Migration Strategy

### Initial Setup (Fresh Database)

```bash
# 1. Configure external tables
# Create prisma.config.ts (see above)

# 2. Initialize Prisma schema
npx prisma init

# 3. Pull existing auth schema from Supabase
npx prisma db pull

# 4. Add managed tables to schema.prisma
# (BrandProfile, UserMetadata, GeneratedAsset)

# 5. Create initial migration
npx prisma migrate dev --name init

# 6. Generate Prisma Client with JSON types
npx prisma generate
```

### Ongoing Development

```bash
# After schema changes:
npx prisma migrate dev --name description_of_change

# Generate updated client:
npx prisma generate

# Reset database (development only):
npx prisma migrate reset
```

## Type Safety Layer

All JSON fields have corresponding Zod schemas and TypeScript types defined in `/lib/types/brand.ts`:

- `BrandColorPalette`
- `BrandTypography`
- `AssetSettings`
- `AssetMetadata`
- `OnboardingProgress`
- `FeatureFlags`
- `TextOverlays`

These types are:
1. Exported from Zod schemas for runtime validation
2. Registered in global `PrismaJson` namespace for compile-time safety
3. Used by `prisma-json-types-generator` to type JSON fields

## Authorization Model

All data access is scoped to the authenticated user via:

1. **Application-level filtering**: Prisma Client Extensions automatically inject `userId` filters
2. **Data Access Layer (DAL)**: `getUserDb()` returns user-scoped Prisma client
3. **Server-only imports**: `"server-only"` package prevents client-side database access

See [research.md#5-authorization-patterns](./research.md#5-authorization-patterns) for implementation details.

## Schema Evolution

When adding new fields or tables:

1. Update `schema.prisma`
2. Create migration: `npx prisma migrate dev --name add_feature`
3. Add corresponding Zod schemas in `/lib/types/`
4. Update `PrismaJson` namespace in `/lib/types/prisma.d.ts`
5. Run `npx prisma generate` to regenerate client
6. Update DAL if new authorization rules needed

## Notes

- **Better-auth manages**: User, Session, Account, Verification tables in auth schema
- **Prisma manages**: BrandProfile, UserMetadata, GeneratedAsset tables in public schema
- **Supabase Storage manages**: Actual file storage (logos, generated assets)
- **Cascading deletes**: Deleting a user automatically deletes all related records
- **Timestamps**: createdAt set on insert, updatedAt auto-updated via `@updatedAt`
- **IDs**: Using `cuid()` for managed tables (better than UUID for database performance)
- **Multi-schema support**: Enabled via `schemas = ["public", "auth"]` in datasource config
