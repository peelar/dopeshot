# Open Questions

Active decisions still needed.

- **Naming for the top rail** — Do we keep "Templates", shift to "Looks", or reframe as "Compositions" for clarity?
- **Variant defaults** — Should each template remember the last-used variant per user, or always open with a single default?
- **Palette extraction fallback** — What shows if color extraction fails: branded default, neutral gradient, or curated fallback set?
- **Upload limits** — Max file size/dimensions we support before we reject or downscale uploads?
- **State persistence** — Do we keep the stateless/session-only model or add lightweight local saves before accounts exist?
- **Multi-format expansion** — When adding headers/covers, do we export one format at a time or allow multi-size export in one action?
- **Watermark/pricing** — When do we introduce a watermark or gate exports once paid tiers exist?
- **Controls placement** — Should the layout/pattern bars stay sticky while scrolling the canvas, or remain anchored to the rail?
