# Open Questions

Active decisions still needed.

- **Layout memory** — Should each layout remember the last-used orientation per user, or always default to auto-detected aspect?
- **Palette extraction fallback** — What shows if color extraction fails: branded default, neutral gradient, or curated fallback set?
- **Multi-format expansion** — When adding headers/covers, do we export one format at a time or allow multi-size export in one action?
- **Effect defaults** — Should effect toggles (Grain/Glow/Grid) default to all-on, all-off, or layout-specific presets?
- **Brand token injection** — When brand integration lands, do effects/backgrounds honor brand tokens automatically or require user opt-in per export?
