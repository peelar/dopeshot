Add Memory feature: Export history with pagination and instant preloading. Logged-in users can now view their export history in a collapsible sidebar, reload previous designs with a single click, and track their creative work over time. The feature includes cursor-based pagination (10 items per page), optimistic UI updates, deduplication to prevent duplicate exports, and seamless integration with the existing export flow. Logged-out users continue to export without friction, with no changes to the export experience.
