Add Gradient Curation Wall - internal dev-only environment for evaluating and curating gradient templates

- New `/gradients` route (dev-only) for systematic gradient evaluation
- 20 gradient templates across 5 sections (linear, radial, conic, layered, monochrome)
- 8 test palettes for cross-palette stress testing
- Global controls for palette switching, UI overlay, and stop marker visualization
- Per-gradient curation with keep/reject status and annotation support
- Full tracking integration for curation decisions
- Index-based addressing (#001-#020) for LLM communication
