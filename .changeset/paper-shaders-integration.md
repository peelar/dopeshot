Add paper-shaders integration for dynamic backgrounds

Integrated @paper-design/shaders-react as a new source for dynamic backgrounds. Includes:

- MeshGradient, GrainGradient, SimplexNoise, NeuroNoise, and more shader types
- 20+ curated shader presets organized by category (gradients, abstract, patterns, organic)
- New "Shaders" tab in background section with preview grid
- Lazy-loaded shader components for optimal bundle size
- Full integration with existing layout and background systems
