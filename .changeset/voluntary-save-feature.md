Transform Memory feature into voluntary Save feature with 5-save limit for free accounts. The export button now changes to a "Save" button (with outline variant and Save icon) after successful export, allowing users to manually choose which exports to keep. The Save button includes a helpful tooltip explaining its purpose. The button automatically resets to "Export PNG" when the design changes or after a successful save. Users can delete saved designs via a trash icon on hover to free up space. Renamed "History" to "Saved" throughout the UI with updated icons (BookmarkCheck) and muted text color. Added save count display ("X of 5") in sidebar header. When at the 5-save limit, the Save button is disabled with a tooltip prompting users to delete a design first. Updated all analytics event names to reflect "saved" terminology.
